# Data Science Coursework

This repository contains my solutions to the University of Cambridge Engineering IB Data Science coursework. The project focuses on implementing and analysing classical data science techniques from first principles using Python and NumPy, with an emphasis on time-series modelling, statistical inference and numerical methods.

## Overview

The coursework explores how mathematical models can be used to understand and predict real-world data. Rather than relying on machine learning libraries, many of the core algorithms are implemented directly using linear algebra and signal processing techniques.

Topics covered include:

- Polynomial regression using least-squares optimisation
- Time-series analysis
- Residual analysis and model evaluation
- Fourier analysis and frequency-domain methods
- Seasonal modelling of time-series data
- Forecasting using combined trend and periodic models

## Exercises

### Exercise 1 – Polynomial Regression

- Implemented polynomial regression using least-squares methods
- Investigated the effect of polynomial order on model performance
- Analysed residuals to assess goodness of fit
- Compared models using statistical error metrics

### Exercise 2 – Fourier Analysis

- Applied the Discrete Fourier Transform to identify periodic components in time-series data
- Used power spectra to determine dominant frequencies
- Reconstructed signals using selected frequency components
- Investigated the relationship between frequency-domain and time-domain representations

### Exercise 3 – Time-Series Forecasting

- Combined polynomial trend estimation with sinusoidal models
- Built predictive models for real-world datasets
- Evaluated forecasting accuracy using statistical metrics
- Investigated model complexity and generalisation performance
